## Explicit limits

- Optional embeddings are deferred. Auxiliary judgment usage has no configured prices: show unpriced, not free.
- Concierge currently uses its model to choose among explicitly permitted agents; a dedicated fast-judgment
  recommendation inside Concierge is not implemented. Global Auto agent routing is separate. No model auto-routing.
- No real cloud sign-ins, personal Apple records, Keychain access or native Automation permission round-trips were
  exercised. Apple tool readiness is not proof of permission.
- Apple Calendar does not expand recurring instances; returned events are not a complete availability check.
- The headless management API is an unauthenticated development/test boundary. Disabling bundled Apple writes does
  not authenticate that API. Use temporary data and fake services, not real sensitive agents.
- Workspace file checks close deterministic symlink escapes, not concurrent filesystem path-swap races. The macOS
  shell sandbox is a separate boundary.
- Builder recovery tests cover process termination/injected failures, not actual power cuts or every filesystem.
  app.db now uses synchronous=FULL; see `internal/agents/DURABILITY.md` for limits and failure behavior.
- Unreleased memory migration 00012 was amended. Disposable data created from the earlier v0.4 schema must be
  recreated; no released/real-person database is claimed migrated from that draft schema.
- Native WebView, dialogs, notifications and installation require native verification before claiming it.
