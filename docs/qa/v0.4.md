## Explicit limits

- Optional embeddings are deferred; memory auxiliary judgment usage is recorded as unpriced, not free.
- No real cloud sign-ins, personal Apple records, Keychain access or native Automation permission round-trips were
  exercised. Apple tool readiness is not proof of permission.
- Apple Calendar reads do not expand recurring event instances; returned events are not a complete availability check.
- Headless management API authentication is a separate development-server boundary; disabling bundled Apple writes
  does not claim that the management API itself has become authenticated.
- Native WebView, file dialogs, notifications and installation still require native verification before claiming it.
