# v0.2.0 post-release verification

Result: PASS for the artifact and source-tag checks below. Native desktop execution is not covered.

## Released artifacts

- GitHub release: https://github.com/ncecere/pi-local/releases/tag/v0.2.0
- Immutable tag commit: `848b7fd80cc1001fc13855bf03899b58388385c3`.
- Downloaded the ARM64 DMG, ZIP, ZIP signature and SHA256SUMS.
- All four GitHub SHA-256 digests matched; both archive checksums matched SHA256SUMS.
- ZIP Ed25519 signature verified using the public key from the tagged `internal/update/key.go`.
- ZIP CRC check passed; both packaged plist versions were `0.2.0`.

## Source-tag regressions

Built the runtime, frontend and headless server in a disposable detached worktree of the release tag, using frozen
lockfiles. All four selected Go tests passed uncached (none failed or skipped):

- `TestMessagesCarryAttachments`
- `TestBashDoesNotSeeTheRuntimesKeys`
- `TestAConversationRunsOnTheModelThePersonChose`
- `TestAgentsAskNotifyAndKeepAChecklist`

A browser smoke flow against that tag-built server passed: welcome page, enable demo model, create an agent from the
Writer & editor template, send a message, receive the complete demo reply. No browser errors were reported.

## Limits

The browser smoke used the tagged source build, not the shipped native app binary. DMG installation, Gatekeeper,
native windows/dialogs, OS notifications, Keychain and in-app updating were not exercised. Artifact signature and
checksum verification must not be described as verification of these native flows.

All test data was temporary and secrets were in memory. The owned server/browser, detached worktree and downloads
were removed. The real app data and Keychain were untouched. Verification used `openai-codex/gpt-6.1-sol`.
