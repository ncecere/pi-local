`windows-2025` amd64 build/test-compile job, scoped to this isolated branch and
`v0.5` with relevant paths; manual dispatch is also branch-guarded. It pins
Go **1.26.10**, Node **22.23.0**, and checks package-cwd pnpm **11.18.0** from
the existing packageManager declarations. Frozen assets precede embedding.

cross-build. Owned runner-temporary outputs are removed on exit. An always-run
step rejects go.mod/go.sum or pnpm lockfile mutation even if an earlier step
fails. No command is allowed to fail silently; existing workflows are unchanged.

The job uses `go test -c` only: it never runs tests, the desktop test binary,
the desktop app, the server, or packaging/release commands, and uploads no
binaries. In particular there is no Wails production-constructor scratch QA. The existing
local Mac cmd/host tests use synthetic callbacks, owned test-binary helpers,
and temporary HOME/plist data; they do not start the app or native OS services.
