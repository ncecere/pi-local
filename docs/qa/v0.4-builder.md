## Deliberate limits

Builder inputs support existing document knowledge folders under the normal folder validation rules and installed
shared skills selected by name. The complete normalized YAML is always shown for human approval, regardless of
profile. Omitted knowledge/skills stay unchanged on update; `knowledge: {folders: []}` and `skills: []` clear them.
Missing skills, imports, supporting file paths, credentials, setup commands and unknown settings fail explicitly.
Schedules are first schedule additions, not edits to existing schedules. Concierge uses ordinary allowed-agent
calls; it adds no all-agent permission and no model routing. Optional routing judgments were not added.
