## Boundaries

All automated QA uses scratch data and memory-only secrets. The native layout harness does not call production
setup, keyring APIs, or the production single-instance ID. Browser layout captures are not native WebKit evidence;
the grouped-navigation body was browser-tested, while the unchanged titlebar was separately measured natively.
No actual personal Apple/cloud operations or notification activation are claimed verified. Local builds opened at
the user's request use their normal profile; automated tests never attach to or inspect that running instance.
