## Scope

New `packaging/licenses/go-graph-evidence.mjs` implements only explicit
`write|assert --target windows-amd64|linux-amd64`, fixed script-resolved worktree,
`./cmd/pi-local`, and `.cache/licenses/go-graph/<target>/production.json`.
Its separate schema-1 `kind: native-go-graph-evidence` envelope always says
`distributionComplete: false`. It does not consume linked binary build info or
require equality with linked binary module sets.

Real Node host rejection precedes every Go subprocess/write. On a matching
Windows/Linux Node host, bounded Go identity probes require matching Go host,
effective selection and exact Go 1.26.10 before offline verify/list commands.
Go env/version probes and graph commands all have before/finally-after module
hash guards, plus whole-operation/prepublication guards. Globals are preserved;
subprocesses alone disable saved Go env/workspaces, toolchain switching and
network module lookup. Mutation fails without restoration. No custom host, root,
output, tag, binary or Go-executor entrypoint exists in the native CLI.

The full graph/source/artifact/observations snapshot is recomputed for assert;
stored graphs are not an oracle. Sorted selected modules include actual CLI
Sum/GoModSum metadata; selected package files and both current dist maps are
hashed. Standard packages bind to the observed SDK, including valid compiler
`unsafe` with no Dir/files. Cgo `C` is an explicit pseudo-import. No tests,
ignored files, external C headers or native-library license inference is added.
Bounded JSON grammar scanning handles adjacent Go objects/escapes and rejects
duplicate keys. Full-object/canonical-byte comparisons reject stale/unknown
claims. Guarded staging/rename follows successful snapshots only.

Both existing compile workflows add only needed graph/policy path triggers,
feature-branch push/ref allowlisting, the new Node unit command, explicit guarded
readonly module hydration, and post-assets offline write/assert/repeat-hash steps.
They keep pinned Go 1.26.10, Node 22.23.0, package-cwd pnpm 11.18.0 and frozen
installs. Existing compile/test-compile checks and Ubuntu stock GTK4/WebKitGTK6,
`file`, `go version -m`, `readelf` checks remain; no executable launch is added.
NOTICE_TARGET is not set globally, so existing default Node receipts stay Schema 1.
The Node-only Phase 1 workflow is untouched. New commands/trust limits are in
[GO-GRAPH-EVIDENCE.md](../../packaging/licenses/GO-GRAPH-EVIDENCE.md).
