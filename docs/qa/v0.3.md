# v0.3 verification

Pre-release browser QA was run by two testers, using separate temporary data folders and in-memory secrets. No real
service sign-ins or personal data were used. The fake model, judge and search services are in
`scripts/e2e/fake-services.mjs`. The original testers used Sonnet before the model change; all recovery, fixes and
subsequent QA use `openai-codex/gpt-6.1-sol`.

## Covered

- Approval profiles, rules, approve/deny/always-allow, compound-command guard and optional judgment tightening.
- macOS sandbox: workspace writes succeed, home writes and SSH access blocked, networking disabled when requested.
- Secret scrubbing: credential-like text and MCP tokens hidden; ordinary settings such as `production` preserved.
- Activity filters, pagination, CSV export, per-agent view and conversation timeline.
- Prices, exact usage cost arithmetic, agent/app budgets, stop/warn, scheduled-run refusals and raised limits.
- Manual and automatic backups, cancellation/deletion, archive contents, restore across a server restart, preservation
  of the old data folder, diagnostic redaction.
- Chat, model selection, attachments and memory regressions; layouts at 1280×900 and 900×700.

## Release blockers and follow-up

| Finding | Fix / state |
|---|---|
| Remembered `ls*` also allows `lsof` | Runtime supports word-bounded `ls *` including bare `ls`; frontend offers the bounded pattern and labels exact commands accurately. |
| Custom profile defaults to no approvals | Fixed: Custom starts with safe approvals, with rule management and Undo. |
| Stop during approval omits tool activity | Fix reviewed and integrated; durable approval-ID deduplication covered by targeted tests. |
| A dangling workspace symlink can redirect a write outside the workspace | Fixed in `03774a5`: unresolved file/parent links refused, adapter aliases normalized. Regression tests fail before/pass after the fix; final integrated gate pending. |
| Refused first message leaves an optimistic sidebar thread | Fixed: optimistic thread is removed and the draft remains available. |
| Budget decimal comma becomes a tenfold amount | Fixed: strict money validation accepts decimal comma without changing the amount. |
| Near-budget notice always says 80%, despite higher actual spend | Fixed; both unit and app expectations updated. |
| Loading models at a newly typed judgment server could reuse the saved key | Saved credentials are now reused only for the saved origin; cross-origin regression test passes. |
| A judgment server redirect could forward its credential or judged text elsewhere | Redirect policy restricts scheme, hostname and effective port; tests cover other ports, subdomains, TLS downgrade, redirect limits, and the app API. |
| Angle-bracket text disappears; timeline shows diagnostic markup | Fixed: Markdown HTML renders as literal text; timeline previews strip diagnostic markup. |
| Network-off failure mislabelled as a write refusal | Runtime handles socket tracebacks and silent curl exit codes; targeted tests pass. |
| Rule patterns accept control characters | Go config rejects control characters; API regression tests pass. |
| Reminder tool replies in raw UTC | Replies use the schedule's local time zone; default is the computer's time zone. |
| Diagnostics omit stored MCP errors | Diagnostic input includes MCP catalog failures; redaction regression test passes. |
| Settings tabs clipped; budget visibility, rule management and money formatting unclear | Fixed: reachable settings tabs, agent/app budget banners, rule descriptions, consistent money formatting and restore feedback. |

A focused GPT security review found the redirect issue above; it reported no other concrete blockers in the reviewed
approval and audit fixes. The redirect fix passed targeted unit and application tests and the integrated local/CI gates.

The workspace file guard now refuses unresolved symlinks, even when their missing target would be inside the
workspace. It remains a path-based guard, not a descriptor-relative filesystem sandbox: concurrent file/parent swaps
between checking and use are not claimed safe. The macOS shell sandbox is a separate boundary.

Native notification buttons have compiled and passed unit-level checks, but have not yet been exercised by a person
in the packaged macOS app. Windows and Linux sandbox implementations are not claimed here; those belong to v0.5.
