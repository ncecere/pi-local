# v0.3 verification

## Release packaging correction

The immutable `v0.3.0` tag points to `33ac1ca`; its application test job passed, but release run
[39645435965](https://github.com/ncecere/pi-local/actions/runs/39645435965) stopped in packaging before publication.
Corepack was invoked from the repository root via `pnpm --dir`, selected pnpm 12, and rejected the projects' pinned
pnpm 11.18.0. The correction runs pnpm after entering each project directory, matching the already-working dependency
build commands, with regression assertions. Keep the original tag unchanged; publish the correction as v0.3.1.
All nine notice tests passed after the correction. A real isolated macOS bundle build completed, with full notices,
plist version 0.3.1 and strict ad-hoc signature verification. The app was not launched; no release key was used.

The detached v0.3.0 source smoke passed six uncached supervisor tests, 32 workspace/document tests and browser smoke
at 1280×900/900×700. This is source evidence only, not verification of published binaries. Exact report and evidence:
`pai-local-v03-release-verify/.cache/v03-release-smoke/REPORT.md`. No native app, real providers or Keychain were used.

Pre-release browser QA was run by two testers, using separate temporary data folders and in-memory secrets. No real
service sign-ins or personal data were used. The fake model, judge and search services are in
`scripts/e2e/fake-services.mjs`. The original testers used Sonnet before the model change; all recovery, fixes and
subsequent QA use `openai-codex/gpt-6.1-sol`.
