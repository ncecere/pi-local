# v0.3 verification

Pre-release browser QA was run by two testers, using separate temporary data folders and in-memory secrets. No real
service sign-ins or personal data were used. The fake model, judge and search services are in
`scripts/e2e/fake-services.mjs`. The original testers used Sonnet before the model change; all recovery, fixes and
subsequent QA use `openai-codex/gpt-6.1-sol`.

## Covered

- Approval profiles, rules, approve/deny/always-allow, compound-command guard and optional judgment tightening.
- macOS sandbox: workspace writes succeed, home writes and SSH access blocked, networking disabled when requested.
- Secret scrubbing: credential-like text and MCP tokens hidden; ordinary settings such as `production` preserved.
- Activity filters, pagination, CSV export, per-agent view and conversation timeline.
- Prices, exact usage cost arithmetic, agent/app budgets, stop/warn, scheduled-run refusals and raised limits.
- Manual and automatic backups, cancellation/deletion, archive contents, restore across a server restart, preservation
  of the old data folder, diagnostic redaction.
- Chat, model selection, attachments and memory regressions; layouts at 1280×900 and 900×700.

## Release blockers and follow-up

| Finding | Fix / state |
|---|---|
| Remembered `ls*` also allows `lsof` | Runtime supports word-bounded `ls *` including bare `ls`; frontend suggestion change in progress. |
| Custom profile defaults to no approvals | Frontend fix in progress. |
| Stop during approval omits tool activity | Isolated fix reviewed; pending integration and full tests. |
| Refused first message leaves an optimistic sidebar thread | Frontend rollback/draft-preservation fix in progress. |
| Budget decimal comma becomes a tenfold amount | Frontend validation/parsing fix in progress. |
| Near-budget notice always says 80%, despite higher actual spend | Fixed; both unit and app expectations updated. |
| Angle-bracket text disappears; timeline shows diagnostic markup | Frontend renderer/preview fixes in progress. |
| Network-off failure mislabelled as a write refusal | Runtime handles socket tracebacks and silent curl exit codes; targeted tests pass. |
| Rule patterns accept control characters | Go config rejects control characters; API regression tests pass. |
| Reminder tool replies in raw UTC | Replies use the schedule's local time zone; default is the computer's time zone. |
| Diagnostics omit stored MCP errors | Diagnostic input includes MCP catalog failures; redaction regression test passes. |
| Settings tabs clipped; budget visibility, rule management and money formatting unclear | Frontend polish batch in progress. |

## Release gates

- [ ] Integrated `make check` (not merely separate workstream test runs).
- [ ] Browser regression check of the medium-severity fixes.
- [ ] CI green on the release commit.
- [ ] Tag v0.3.0, verify archive checksums/signature/version and release notes.
- [ ] Post-release smoke test against the immutable release revision.

Native notification buttons have compiled and passed unit-level checks, but have not yet been exercised by a person
in the packaged macOS app. Windows and Linux sandbox implementations are not claimed here; those belong to v0.5.
